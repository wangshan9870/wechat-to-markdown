# WeChat to Markdown 隐私政策

生效日期：正式发布日（2026年8月18日）

运营者：王帅

联系方式：GitHub Issues（https://github.com/wangshan9870/wechat-to-markdown/issues）

## 我们处理哪些信息

扩展仅在用户主动使用时读取当前微信公众号文章或公开合集页面，用于在浏览器本地生成 Markdown、图片归档和 ZIP。处理内容可能包括文章标题、作者、公众号名称、发布时间、正文、图片地址和来源链接。

上述文章数据不上传到运营者服务器。生成的文件由用户通过浏览器下载到自行选择的位置。

扩展会在浏览器本地存储图片下载偏好、合集下载断点、随机安装标识和授权缓存。验证请求仅包含邮箱（用户主动提供）、卡密（用户主动输入）、随机安装 ID 和扩展版本，不包含文章内容、文章 URL、公众号名称、图片、Cookie、Token 或完整浏览历史。

## 使用目的

信息仅用于提供文章转换、本地归档、任务恢复、许可证验证、安全与故障诊断。我们不出售用户数据，不用于广告、画像、信用评估或训练 AI 模型。

## 第三方与网络请求

- 微信页面和图片仍由用户浏览器向对应站点请求。
- 授权验证由运营者自建授权服务处理（https://work.bzjkmn.cn），扩展仅发送邮箱、卡密、随机安装 ID 和扩展版本。
- 付款通过微信转账等线下渠道完成；运营者不在扩展中直接收集银行卡信息。

## 保存期限与安全

文章内容不由运营者保存。本地偏好和断点由用户清除扩展数据或卸载扩展时删除。订单、财务和许可证记录按履行合同、售后及法定义务所需期限保存。所有授权和结算通信使用 HTTPS。

## 用户权利

用户可以停止使用或卸载扩展、清除本地扩展数据，并通过支持页面（GitHub Issues）请求查询、更正或删除由运营者持有的许可证和联系信息；法律要求保留的交易记录除外。

## 儿童与政策变更

本产品不面向未满适用法定年龄的儿童。如数据处理方式发生实质变化，我们会更新本政策、生效日期及商店隐私声明，并在需要时取得用户同意。

## 联系我们

隐私问题请通过 GitHub Issues 联系我们：https://github.com/wangshan9870/wechat-to-markdown/issues。公开渠道沟通时，请不要在 Issue 中粘贴文章正文、Cookie、身份证件或其他敏感信息。
