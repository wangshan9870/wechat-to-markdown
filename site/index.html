# FAQ

开始前，你可能还想确认这些事

免费版可以一直用吗？

可以。单篇文章导出是长期免费能力，不要求先购买永久版。

会上传我的文章吗？

不会。正文读取、转换与打包在浏览器本地完成，授权服务不接收文章内容。

普通网页也能保存吗？

支持博客、新闻和教程等文章型网页。复杂应用页或需要登录才能读取的内容可能无法完整识别。

导出的 Markdown 能放进哪里？

可直接用于 Obsidian、思源、Typora、VS Code 及其他支持 Markdown 的工具。

合集归档会绕过微信权限吗？

不会。扩展只处理用户已打开且无需绕过访问控制即可访问的公开文章与合集页面。

永久版为什么不是订阅？

当前核心能力在本地运行，没有持续云端处理成本，因此采用 ¥29 一次买断。
