三步完成一次转换

  1. 打开有权访问的公众号文章

    刷新文章页面，等待右侧出现文章目录与保存入口；也可以点击浏览器工具栏中的扩展图标。

  2. 选择 Markdown 和图片偏好

    只需要文本时直接导出 `.md`；需要离线图片时开启“下载文章图片”，扩展会生成 ZIP。

  3. 保存到自己的目录

    导出的文件可直接打开，也可以移动到 Git 仓库、Obsidian Vault 或其他 Markdown 工具中。

图片本地化如何工作

关闭图片下载时，Markdown 保留原网络图片地址，文件更小；开启后，扩展下载当前文章图片并将路径改写为本地相对地址。如果个别图片下载失败，会保留原地址并报告失败数量，不会静默删除图片。

推荐做法：临时引用保留网络图片；需要长期离线保存、迁移知识库或担心原图失效时，再开启图片本地化。

哪些页面可能无法完整转换

明确边界

  • 扩展不会绕过登录、付费墙或其他访问控制。
  • 交互式应用、视频页和以脚本动态拼装的复杂页面不一定适合转成文章。
  • 导出文件不代表获得转载、传播或商业使用授权。
  • 网页结构变化可能影响识别；遇到问题可以提交可复现信息。

转换之后，继续整理而不是继续堆文件

单篇 Markdown 适合即时保存；如果你已经积累了大量文章，可以使用本地文章库、公众号合集归档或 Obsidian 导出，把文件组织成可筛选、可备份的资料库。
