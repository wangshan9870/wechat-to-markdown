WeChat to Markdown 是什么？

它是望山开发和维护的 Chrome 扩展，官方网站为 wx2md.com。主要用于微信公众号阅读、保存与 Markdown 导出，也支持用户主动保存普通文章型网页。

文章正文会上传吗？

文章解析、转换和打包在浏览器本地完成，不向运营者上传正文、文章地址或标题。下载图片仍需请求原图片地址；授权验证和版本检查可能连接运营者服务，可选产品统计默认关闭。详见隐私政策。

支持哪些导出格式？

支持 Markdown、HTML、PNG 分享图片，以及通过浏览器打印保存 PDF。Markdown 可以搭配本地图片 ZIP；ZIP 是归档容器，PDF 的排版与输出由浏览器打印功能完成。

免费版可以一直使用吗？

可以。当前免费版每月有 10 次单篇导出额度，Markdown、HTML、PNG 和单篇图片 ZIP 共用额度，失败或取消不扣次；PDF 打印暂不计次。付费权益与最新规则以购买页为准。

怎么放进 Obsidian、思源或 Typora？

导出 Markdown 后，可把文件放入 Obsidian 仓库、导入思源，或用 Typora、VS Code 打开。包含图片时先解压 ZIP，保持文章与图片的相对目录不变；进阶知识库联动属于完整版能力。查看Obsidian 导入教程。

能归档整个公众号合集吗？

支持用户主动发起的公开合集归档，完整版提供完整、增量、分卷和断点继续。免费合集试用与单篇导出额度是不同规则，当前可试用 1 次、最多导出 5 篇；具体见权益说明和合集教程。

能绕过付费墙或访问限制吗？

不能。只能处理你有权访问的内容，不绕过登录、付费墙或平台访问限制，也不提供第三方内容授权。保存到本地不等于获得公开转载或商业使用权；详见服务与版权说明。

普通网页也支持吗？

支持博客、新闻、教程等文章型网页，由你主动点击扩展后采集当前页面。复杂应用、特殊排版或动态加载内容可能无法完整识别；微信公众号是主要适配场景。

GitHub 源码和商店版有什么区别？

公开 Community 仓库包含单篇导出、图片本地化和快捷保存。商店完整版还包含合集归档、授权及付费功能；公开源码不代表商店版的全部能力。安装请使用官方下载安装页。

从哪里安装？需要注册账号吗？

前往下载安装页选择 Chrome 商店版或官网离线 ZIP 版，基础使用无需注册账号。安装后先按首次使用步骤保存一篇文章；购买和卡密激活流程见购买页。

本地文章库会永久保留吗？

数据没有自动过期时间，但本地存储不是永久备份。卸载扩展、清除浏览器数据、更换浏览器配置或离线安装目录可能导致数据丢失；请定期导出文件或进行备份。

图片缺失或导出失败怎么办？

先确认原文章及图片可以正常访问，再重试导出。图片下载失败时会保留网络地址并提示失败数量；这类图片仍可能需要联网查看。排障和反馈入口见使用支持。
