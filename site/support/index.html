先让问题变得可复现

刷新页面、确认版本、记录完整错误。清晰的上下文比“导出不了”更容易得到有效解决。

不要发送敏感信息

反馈时不要提交 Cookie、Token、微信登录信息、未公开文章、付款凭证或身份证件。

安装与更新识别与导出知识库连接购买与激活提交反馈

安装或更新后没有反应

  1. 打开 Chrome 的扩展管理页，确认“网页归档助手”已启用。
  2. 确认当前版本是商店可用的最新版本。
  3. 刷新更新前已经打开的公众号文章页面。
  4. 再次点击页面入口、工具栏图标或使用 Alt+Shift+W。
打开 Chrome Web Store

文章识别、图片或导出失败

  • 确认页面是可以正常阅读的公众号文章或受支持的公开合集。
  • 单篇导出失败时，先关闭“下载文章图片”，确认正文能否单独导出。
  • 只有个别图片失败时，导出的 Markdown 会保留其网络地址并报告失败数量。
  • 普通网页识别失败时，可以使用降级面板保存标题、网址或打印 PDF。
  • 页面提示“扩展已更新”时，刷新当前网页再试，不要重复点击。

Obsidian 或思源连接失败

  • Obsidian：选择包含 .obsidian 的 Vault 根目录。
  • 浏览器提示目录权限失效时，重新选择目录；扩展不会在后台主动弹权限框。
  • 思源：确认桌面端正在运行，本机 API 地址、Token 和笔记本 ID 正确。
  • 不要把思源本机 Token 粘贴到公开 Issue 或截图中。

  • 扩展版本和 Chrome 版本；

  • 界面显示的完整错误文字；
