# 官网不在本仓库

WeChat to Markdown 的正式官网是 [https://wx2md.com](https://wx2md.com)。

本目录以前存放过一份静态站点。那份副本已经落后于线上（sitemap、`product.jsonld` 等与 https://wx2md.com 不一致），继续留在公开仓库会让爬虫和贡献者读到过期信号。线上站点由独立的站点仓库构建并部署，不从本仓库发布。

请不要在这里恢复页面、`robots.txt`、`sitemap.xml`、`product.jsonld` 或安装包，也不要新增把 `site/` 上传到 Cloudflare Pages 的脚本。官网改动请在站点仓库中进行。
