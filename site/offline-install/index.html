解压后的目录就是扩展运行目录。安装后不要删除或随意移动它。

首次安装确认安装后续更新常见提醒数据安全

首次安装

  1. 下载并解压到固定目录

    下载 wechat-to-markdown-3.0.3.zip，解压到不会被清理的位置，例如“文档 / WeChat-to-Markdown”。不要直接在 ZIP 压缩包内打开。

  2. 打开扩展管理页

    Chrome 地址栏输入 chrome://extensions；Edge 输入 edge://extensions。打开页面右上角的“开发者模式”。

  3. 加载已解压的扩展程序

    点击“加载已解压的扩展程序”，选择刚才解压的文件夹。选中的目录里应该直接包含 manifest.json。

  4. 固定扩展并刷新文章页

    把 WeChat to Markdown 固定到浏览器工具栏。刷新安装前已经打开的公众号文章，再点击扩展图标。

确认你装的是正式版本

扩展管理页应显示名称 WeChat to Markdown、版本 3.0.3。官网 ZIP 版与商店版使用同一个固定扩展 ID：kbijkembfnijlgpkeofanhpoaefkddim。

如果扩展 ID 不一致，先不要继续使用。重新从 官方下载页获取 ZIP，并确认选择的是包含 manifest.json 的正确目录。

核对 SHA-256

macOS / Linux 运行：

shasum -a 256 wechat-to-markdown-3.0.3.zip

Windows PowerShell 运行：

Get-FileHash .\wechat-to-markdown-3.0.3.zip -Algorithm SHA256

结果应为：9f08015a8de973e1f76c769cf4810b70b98e885432c35d299378e89e422c88fc

以后如何手动更新

  1. 从 官方下载页获取新版本 ZIP，并核对 SHA-256。
  2. 先在本地文章库下载 JSON 备份，再退出正在进行的合集任务。
  3. 完整解压新版，用全部文件覆盖原来的固定目录，不要卸载旧扩展，也不要加载成第二份副本。
  4. 回到扩展管理页，点击现有 WeChat to Markdown 卡片上的“重新加载”，不是页面顶部的“更新”。
  5. 确认卡片版本已经变化，并刷新更新前打开的公众号或普通网页。
不要通过“删除扩展 → 重新安装”来更新。本地文章库属于浏览器扩展数据，卸载扩展或清理浏览器数据可能导致数据丢失。若从 v3.0.1 之前的随机 ID ZIP 版迁移，请先导出 JSON 备份。

为什么会提示“开发者模式扩展”？

这是 Chrome 对手动加载扩展的正常提醒，不代表文件损坏。确认文件来自 wx2md.com 后，可以选择保留；如果你能够访问 Chrome 商店，改用商店版可以免去这类提醒并获得自动更新。

更新前先保护本地数据

Markdown、HTML 和 ZIP 等已经下载到磁盘的文件不受扩展更新影响。本地文章库则保存在当前浏览器配置中，重要内容应定期导出 JSON 备份，或同步到 Obsidian、思源等你自己的知识库。
