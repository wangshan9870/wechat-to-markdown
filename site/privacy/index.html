隐私政策

生效日期：2026 年 8 月 17 日 · 运营者：王帅

结论：文章和公开合集内容在用户浏览器本地处理，运营者不接收、出售或分析这些内容。

处理的信息

扩展仅在用户主动使用时读取当前微信公众号文章或用户主动打开的公开合集页面，用于生成 Markdown、HTML、图片归档或 ZIP。处理内容可能包括标题、作者、公众号名称、发布时间、正文、图片地址、合集公开列表和来源链接。

处理方式和目的

文章解析、格式转换、图片整理和 ZIP 打包均在用户设备本地完成，只用于提供用户主动请求的导出功能。运营者不接收文章内容、文章地址、公众号名称、图片、Cookie、Token、微信登录信息或完整浏览历史。

本地存储

扩展使用 Chrome 本地存储保存图片下载偏好、合集任务断点、随机安装标识以及用户主动激活后的授权状态。用户可以通过清除扩展数据或卸载扩展删除这些信息。扩展不会把文章正文写入运营者控制的远程数据库。

授权服务

如果用户主动使用 Pro 激活功能，扩展可能会将用户自行填写的邮箱地址、随机安装 ID 和扩展版本发送到隐私权规范中声明的 HTTPS 授权服务，用于确认购买权益和限制激活设备数量。授权服务不接收文章内容、文章 URL、公众号名称、Cookie、Token 或浏览历史。未启用或未使用 Pro 激活时，不会发生该授权请求。

第三方网络请求

微信文章页面由相应平台提供。只有在用户选择图片本地化时，浏览器才会向微信图片域名请求当前文章图片。若导出的文件保留远程图片地址，阅读器打开文件时也可能向相应图片服务器发起请求。

分享、出售和广告

我们不出售用户数据，不将数据用于个性化广告、画像、信用评估或 AI 模型训练，不允许人工读取用户的文章数据，也不将文章数据提供给第三方。订单和授权信息只用于交付、售后、退款及履行必要的法律义务。

Limited Use

本扩展对信息的使用遵守 Chrome Web Store 用户数据政策及 Limited Use 要求。信息只用于提供或改进扩展明确说明的单一用途，不用于无关目的。

用户权利和联系我们

用户可以停止使用扩展、清除本地数据或卸载扩展。如需查询、更正或删除运营者持有的授权信息，请通过支持页面联系。法律要求保留的交易记录除外。请勿在公开 Issue 中提交文章正文、Cookie、Token、身份证件或其他敏感信息。

政策变更

如数据处理方式发生实质变化，我们会更新本政策、生效日期和 Chrome Web Store 隐私声明，并在适用规则要求时取得用户同意。
