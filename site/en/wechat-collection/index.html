Large collections need recoverable progress

Reading, converting and packaging many articles at once can run into memory limits, network failures or background timeouts. Separate volumes give each part a clear saved state. Only archive content you have the right to use.

Your first collection archive

  1. Open a publicly accessible WeChat collection page. The extension reads the displayed article list without collecting or reusing Cookie or Token session credentials.
  2. Choose a save directory and confirm the page’s ascending or descending order. The order is captured when you start the download.
  3. Wait for each volume to finish. Up to 20 articles form a volume; local progress advances only after the file closes successfully and the browser confirms the save.

Interruptions, cancellation and incremental exports

  • Interruption or failure: keep completed volumes and resume from unfinished work.
  • Cancellation: stop the task without marking the current volume complete.
  • Next archive: export newly added articles by default.
  • Full re-export: explicitly reset local progress for the current sort direction; saved files are not deleted.

Resume and incremental history live in the current browser profile. Uninstalling, clearing browser data or changing profiles can remove that history.

Try before buying

Each unlicensed installation can try one successful collection export of up to 5 articles. The trial is used only after a confirmed save and does not write full incremental history. The full plan supports complete volumes, resume, incremental updates and adding collections to the local library. See current pricing and entitlements.

Access and usage boundaries

  • No bypassing login, payment, access controls or platform restrictions.
  • Reading collection articles starts only after your explicit action and does not grant content rights.
  • Compatibility with all future WeChat layouts is not guaranteed.
  • Batch export does not change copyright or usage permissions.
