Questions before you install

Does it upload my articles?

Article parsing and export run in your browser. Article bodies, URLs and titles are not sent to the operator. Image downloads contact the original image host; license checks and updates may contact the operator. Optional product analytics are off by default. See the privacy policy.

Is it free?

You can start without an account. The current free plan includes 10 single-article exports per month, shared across Markdown, HTML, PNG and image ZIP exports; failed or cancelled exports do not count. Browser PDF printing currently does not count. See current plans and limits.

Which formats can I export?

Export Markdown, HTML or PNG, or save a PDF through the browser print dialog. Optional image ZIP archives package files for local reading; keep the extracted folder structure intact.

Can I use it with Obsidian or SiYuan?

Yes. Export Markdown, unzip any image archive, and move the files into your Obsidian vault or import them into SiYuan. Typora and VS Code can also open Markdown. Advanced integrations belong to the full version.

Can I archive a WeChat collection?

The full version supports user-initiated collection archiving, including incremental exports, split archives and resume. A limited free collection trial is available; see the plan details.

Does it bypass paywalls or access restrictions?

No. Use it only for content you have the right to access and use. It does not bypass login, paywalls or platform restrictions, and saving a file does not grant republication rights.

Is the full store version open source?

The public Community repository covers single-article export, local images and quick saving. The full store version also includes collection archiving, licensing and paid features. The public repository does not contain every store feature.

Is the local library a permanent backup?

No. There is no automatic expiry, but uninstalling the extension, clearing browser data or changing browser profiles can remove local data. Export or back up files regularly.
