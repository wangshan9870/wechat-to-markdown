About WeChat to Markdown

A local-first Chrome extension for reading, saving and exporting WeChat Official Account articles. Built and maintained by Wangshan; the official website is wx2md.com.

One product, clear official sources

WeChat to Markdown saves WeChat Official Account articles as Markdown on your computer. Parsing and export run in the browser, without uploading article bodies to the operator. Optional image archives help you keep reading in Obsidian, SiYuan, Typora or VS Code.

What it does

  • Preserves article titles, authors, account names, publication dates and source links when available.
  • Exports Markdown, HTML and PNG; PDF uses the browser print dialog.
  • Optionally saves images in a ZIP with relative file paths.
  • The full version supports collection archiving, local library batch operations and knowledge-base integrations. See plan details.

Where your data goes

Article parsing, image processing, ZIP packaging and the article library run locally. License checks, updates and optional product analytics may contact the operator; these requests do not contain article bodies, URLs or titles. Optional product analytics are off by default. Image downloads contact the original image host. See the privacy policy.

Community source and the full version

The public Community repository includes single-article export, local images and quick saving. The full store version additionally includes collection archiving, licensing and paid features. The public repository does not contain every store feature.

Similarly named projects

Other scripts and command-line projects use names such as wechat2md and wechatmp2markdown. They are separate projects. Identify this product by the name WeChat to Markdown, the website wx2md.com and the official repository.
