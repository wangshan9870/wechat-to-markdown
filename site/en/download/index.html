Distribution channels are not the Community edition

Community v0.3.0 open-sources only the core MVP: single WeChat article Markdown exports, optional image ZIPs and quick saving. It does not include ordinary web-page extraction, the local article library or collection archiving, and is not the store free plan. The store product is versioned independently and combines free and paid Pro features in one extension. The official offline ZIP is another distribution channel with the same entitlement rules; release versions may temporarily differ during store review.

The free plan includes 10 single-article exports per month. Active paid licenses allow unlimited single-article exports; purchased lifetime licenses remain unlimited permanently. Basic local-library reading and search are free. See free limits and Pro entitlements.

Chrome Web Store — automatic updates

Recommended when you can access the store. Install with one click; Chrome handles subsequent updates and verifies the extension source. Developer mode is not required.

Official ZIP — manual updates

Download directly from wx2md.com if the store is unavailable. Extract the ZIP and use “Load unpacked”. The extension can notify you of updates, but you must replace the files and reload it yourself.
