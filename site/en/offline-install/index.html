Install and update the official ZIP

Keep the unpacked folder in one permanent location. ZIP installation changes how you install and update, not whether image downloads, licensing or version checks use the network.

Four installation steps

  1. Download v3.1.2 and extract it into a permanent folder, such as Documents / WeChat-to-Markdown. Do not run it inside the ZIP.
  2. Open chrome://extensions in Chrome or edge://extensions in Edge. Enable Developer mode.
  3. Click “Load unpacked” and select the extracted folder that directly contains manifest.json.
  4. Pin the extension and refresh articles that were open before installation. Do not delete or move the extracted folder.

Confirm the official version

The extension card should show WeChat to Markdown, version 3.1.2, and ID kbijkembfnijlgpkeofanhpoaefkddim. The official ZIP and store versions use this fixed ID. If it differs, stop and obtain the ZIP again from the official download page.

On macOS or Linux:

shasum -a 256 wechat-to-markdown-3.1.2.zip

On Windows PowerShell:

Get-FileHash .\wechat-to-markdown-3.1.2.zip -Algorithm SHA256

Expected SHA-256:

33d042652b2bd78a80f646b79a388eb1341cbe5a5f78f2f42c6d6f66fd97008f

Update in place

  1. Download the latest ZIP from the download page and verify its hash.
  2. Export a JSON backup from the local library and stop any collection task.
  3. Extract all new files over the original permanent directory. Do not uninstall the extension or load a second copy.
  4. Click “Reload” on the existing extension card, not “Update” at the top of the management page.
  5. Confirm the version changed and refresh any article pages already open.

If migrating from a pre-v3.0.1 ZIP with a random extension ID, export a JSON backup first. Uninstalling or clearing browser data can remove library data.

Developer-mode warnings

Chrome normally warns about manually loaded extensions. Confirm the files came from wx2md.com before keeping them enabled. If you can access the store, that version avoids manual update steps.

Protect your local data

Files already downloaded to disk remain yours. The article library and progress records belong to the current browser profile; uninstalling, clearing data or changing installation folders can make them unavailable. Back up regularly. Get support.
