Keep the source with the content

Copying text by hand can lose heading levels, image portability and source context. WeChat to Markdown adds source metadata and aims to preserve the semantics of links, lists, quotations and tables.

---
title: "An article worth keeping"
author: "Author name"
account: "Example account"
published: "2026-08-31"
source: "https://mp.weixin.qq.com/..."
---
# Article heading
Text, links and image references.

Convert in three steps

  1. Open an article you have permission to save. Refresh the page, then use the page controls or toolbar popup.
  2. Choose Markdown. For offline images, enable image downloads to generate a ZIP.
  3. Save to your own directory. Open the file directly or move it into a Git repository, Obsidian vault or another Markdown tool.

How local images work

With image downloads off, Markdown retains the original network image URLs. With downloads on, images are saved and links become relative local paths. Failed image downloads retain the original URL and are reported, rather than silently removed.

Keep network images for temporary references; use local images for long-term offline reading or migration between tools.

Conversion limits

  • No bypassing login, paywalls or other access controls.
  • Interactive apps, video pages and complex dynamically generated pages may not convert fully.
  • Exporting does not grant republication or commercial-use rights.
  • Page structure changes can affect extraction. Share reproducible, non-sensitive details with support.

Organize what you save

Use the local library, collection archiving and the Obsidian workflow to keep files searchable and backed up.
