Installation and updates

  1. Confirm WeChat to Markdown is enabled on the Chrome extensions page.
  2. Compare your version with the official download page.
  3. Refresh articles that were open before the update.
  4. Try the page controls, toolbar icon or Alt+Shift+W.

ZIP installation and update guide

Article, image or export failures

  • Check that the article or supported public collection can be read normally.
  • For single-article failures, disable image downloads to isolate text export.
  • Individual failed images retain network URLs in Markdown; the failure count is reported.
  • If ordinary-page extraction fails, use the fallback panel to save the title and URL or print a PDF.
  • If the page says the extension was updated, refresh rather than repeatedly clicking.

Obsidian or SiYuan connection issues

  • For Obsidian, select the vault root containing .obsidian.
  • If directory access expires, select the folder again.
  • For SiYuan, make sure the desktop app is running and the local API address, token and notebook ID are correct.
  • Never include your SiYuan token in a public issue or screenshot.

License codes and devices

Open the activation screen from the toolbar popup, article, collection or local library. Paste your code and submit once to redeem it and activate this device. The website never asks you to enter a license code.

If a code is already redeemed, try restoring the current device with the same code. For device limits, invalid or revoked codes, retain the complete error and contact support privately. Do not publish license codes on GitHub.

What to include in a report

  • Extension and Chrome versions.
  • Page type: single WeChat article, public collection or ordinary web page.
  • Exact steps from opening the page to the failure.
  • Full error text and a redacted screenshot.
