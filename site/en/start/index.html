Your first Markdown export

  1. Pin WeChat to Markdown using the puzzle icon in the Chrome toolbar.
  2. Open a WeChat Official Account article you have permission to save. Refresh articles that were open before installation.
  3. Choose Markdown in the page controls or extension popup. Enable image downloads if needed, then save the file.

No controls? Refresh the article.

  • Make sure the extension is enabled in Chrome.
  • Check that the article can be read normally.
  • Refresh, then click the toolbar icon. If it still fails, visit support.

Start with the free allowance

The free plan includes 10 single-article exports per month across Markdown, HTML, PNG and image ZIP. Failed or cancelled exports do not count; browser PDF printing currently does not count. A separate collection trial allows one successful export of up to 5 articles. See current plans.
