一句话说明

WeChat to Markdown 是本地优先的 Chrome 扩展，帮助你把微信公众号文章保存为电脑上的 Markdown 文件。解析与导出在浏览器内完成，不把正文上传给运营者；可选本地图片归档，方便在 Obsidian、思源、Typora 或 VS Code 中继续阅读。

WeChat to Markdown is a local-first Chrome extension for saving WeChat Official Account articles as Markdown. Article parsing and export run in your browser. Read the English overview →

wx2md 不是一个泛指的转换脚本名称，而是 WeChat to Markdown 这款浏览器扩展的常用简称。官网、安装入口、使用说明和隐私政策都由 wx2md.com 承接。

它能做什么

  • 在用户主动打开的文章页面识别标题、作者、公众号、时间和正文。
  • 导出 Markdown、HTML、PDF 或图片，并保留来源链接和文章结构。
  • 可选把正文图片下载到本地 ZIP，继续整理到 Obsidian、思源、Typora、VS Code 或其他 Markdown 工具。
  • 支持公众号合集归档、本地文章库和增量整理等完整功能，具体权益以购买页为准。

文章会上传到服务器吗？

文章解析、Markdown 生成、图片处理、ZIP 打包和文章库保存均在浏览器本地完成，文章正文不会上传给运营者。扩展仍可能为了授权验证、版本检查和默认关闭的可选产品使用统计连接运营者服务；这些连接不包含文章正文、文章地址或标题。完整边界见隐私政策服务与版权说明。

公开源码与完整版

公开 Community v0.3.0 仅开源核心 MVP：公众号单篇 Markdown、图片 ZIP 和快捷保存，不包含普通网页适配、本地文章库或合集归档。它不等于商店免费版。商店产品独立迭代，在同一安装包内提供免费与会员（Pro / 完整版）权益；官网离线 ZIP 是另一安装渠道，适用相同权益规则，版本可能因审核进度暂时不同。安装统一从下载安装页选择渠道，当前免费额度和付费权益见购买页。

它和其他 wx2md / wechat2md 项目是什么关系？

网上存在多个名称相近的开源脚本或命令行项目，例如 wechat2md、wechatmp2markdown。它们与本产品不是同一个项目。判断本产品时，请以产品名 WeChat to Markdown、官网 wx2md.com、官方安装页和下方官方仓库为准。
