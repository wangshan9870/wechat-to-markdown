# FIRST SAVE

只做三件事

先完成一次免费单篇导出。合集、文章库和知识库联动可以之后再了解。

  1. CHROME TOOLBAR

    把扩展固定到工具栏

    点击 Chrome 右上角的拼图图标，在 WeChat to Markdown 旁点击图钉。以后找入口不用再翻扩展列表。

    Chrome
    地址栏🧩📌 WeChat to Markdown

  2. MP.WEIXIN.QQ.COM

    打开一篇你有权访问的公众号文章

    如果文章在安装扩展之前就已经打开，请先刷新页面。刷新后，扩展才能识别正文并显示阅读与保存入口。

    公众号文章

  3. EXPORT MARKDOWN

    点击扩展，选择 Markdown

    在页面入口或工具栏弹窗中选择 Markdown。可按需开启“下载文章图片”，然后保存文件到本地。

    保存文章Markdown + YAML可选：图片本地化保存到本地 →

QUICK CHECK

没看到入口，先刷新当前文章页

扩展安装后不会自动重载已经打开的网页。大多数“安装后没反应”，刷新一次就能解决。

  • 确认扩展管理页中已启用
  • 确认当前是可正常阅读的公众号文章
  • 刷新页面后再点击工具栏扩展图标
