API · STORE

WeChat to Markdown Store API

这是 wx2md 购买页使用的订单服务接口说明。机器可读的 OpenAPI 规范位于 /api/openapi.json。

API 根地址

https://work.bzjkmn.cn/api/v1/store/
请求方式：POST
认证：由订单链接中的访问凭证控制

# ENDPOINTS

接口用途

购买页只发送必要的订单字段，不发送文章正文、浏览历史或 Cookie。

POST /products/list

查询套餐

返回当前可在线购买的 WeChat to Markdown 套餐。

POST /orders/create

创建订单

根据产品编号和订单访问凭证创建或读取订单。

POST /orders/detail

查询订单

返回支付状态、发货状态和已交付的授权信息。
